## 1. 结论

**通过（立项）**。以 `agent.web.write` 作为**写入侧独立高危权限**落地，与只读的 `agent.web` 分离授予；
命名取代原 §8.4 / Phase E 文档中的暂称 `agent.web.upload`（后者语义只覆盖上传，无法表达草稿增删与发布提交）。

立项的前提条件是下列五条约束**同时**成立（缺一不立项）：

1. **host 白名单**：仅允许逐字符命中白名单的 host，当前白名单 = `api.weixin.qq.com`（无前缀 / 后缀 / 通配、无 IP 字面量、无端口）。
2. **显式 method/body**：`method` 必填且仅 `GET` / `POST`；载荷仅 JSON 对象或受控 multipart，由底座序列化，积木不得指定任意请求头。
3. **multipart 受控**：单次单文件、≤ 10 MB、文件来源限 `fs.pick` 回执路径或逻辑进程私有目录、文件名净化。
4. **凭据不入日志不入桥**：凭据只留逻辑进程私有目录（0600）；底座不做凭据注入 / 托管 / 缓存；审计与日志对 query / body 只记键名与字节数。
5. **高危标红 + 首调二次确认 + 审计留痕**：安装页标红且默认不勾、勾选后二次确认，首次实际调用再一次性确认；每次调用写入审计（host / method / path / 响应码），保留 30 天。

## 2. 为什么不能沿用 `agent.web`

| 项 | `agent.web`（现状） | `agent.web.write`（本次新增） |
|---|---|---|
| 语义 | 联网检索 + 只读抓取 | 受控写入（提交 / 上传） |
| 方法 | 只读 | `GET` / `POST`（显式） |
| 载荷 | 无 body | JSON body / 受控 multipart |
| 风险级别 | 中 | **高**（标红） |
| 授权 | 与检索同项 | **独立项**，可单独不授予 |

结论：写入不可逆且影响面大于只读抓取（G4 判定），必须独立授权面 + 独立审计，故不并入 `agent.web`。

## 3. 安全论证要点

- **最小授权面**：host 白名单为显式正列举，扩展须走契约修订 + 安全评审并在底座登记；manifest **不得**自定义 host。
- **凭据风险隔离**：底座不成为凭据托管方（2026-09-26 待决项中的核心顾虑），凭据不出逻辑进程私有目录、不入日志、不入桥、不入 UI 文档与 `state_snapshot`。
- **不可绕过的边界**：拒绝重定向跟随（`redirected` 恒 false）、拒绝非 https、拒绝带端口 / IP 字面量、拒绝未知方法；白名单外请求**不发起任何网络连接**。
- **可审计**：调用即留痕（host / method / path / 响应码 / 字节数），参数与响应正文脱敏。
- **失败不静默**：响应超限以 `truncated: true` 明示；网络失败须映射为可读业务错误态，不得折叠为「能力未就绪」的降级横幅。
- **不新增协议面**：不新增错误码，复用 `4305` / `4309` / `4310`；不动 §4 方法总表与帧格式。

## 5. 对 wechat-mp（Phase E）的能力映射

| 业务动作 | 接口 | 依赖本能力 | 备注 |
|---|---|---|---|
| 取 / 刷新 token | `cgi-bin/token`（GET） | 是 | 凭据（`appsecret`）不进参数，仅逻辑进程私有目录持有 |
| 草稿列表 / 计数 | `draft/batchget`、`draft/count` | 是 | 探测类只读，但需 POST body，故仍走本能力 |
| 草稿新增 / 删除 | `draft/add`、`draft/delete` | 是 | JSON body |
| 素材上传 | `material/add_material`、`media/uploadimg` | 是 | 受控 multipart，≤ 10 MB |
| 发布探测 / 提交 / 查询 | `freepublish/batchget`、`freepublish/submit`、`freepublish/get` | 是 | 无权限账号回 `48001` → 积木须隐藏发布入口而非报错 |
| 草稿列表只读展示、账户配置、剪贴板复制 | — | 否 | 能力未就绪期间的降级范围 |

**降级口径**：宿主 handler 未就绪或权限未授予时，素材上传按 `upload_blocked` 横幅**明确告知**（不静默失败）；
发布入口按权限探测四态（`unknown` / `probing` / `granted` / `denied`）驱动，`48001` 视为 `denied` 并隐藏提交入口。

## 7. 校验与回归要求

1. 白名单外 host / 非 https / 带端口：拒绝且不发连接，计一次违规（回归项）。
